# TAMARINDO — Wings y Antojos 🍗🍔

> **El Antojo No Se Negocia.**
> Plataforma web de alta conversión y experiencia gastronómica para TAMARINDO Fast Food.

---

## 🌮 Especialidades
- **Tenders Extra Crujientes**: Pechuga fresca marinada 12 horas con empanizado artesanal secreto.
- **Smash Burgers Monstruosas**: Carne selecta aplastada al punto crisp con queso cheddar fundido y pan brioche.
- **Boneless & Alitas**: Bañados en salsa insignia Tamarindo Habanero, Búfalo, BBQ Ahumada o Ajo Parmesano.
- **Dedos de Queso**: Mozzarella real con *cheese pull* supremo.

---

## 🚀 Características Técnicas
- **Arquitectura Limpia & Vanilla Web**: Estructurado en HTML5 semántico, CSS3 modular (con sistema de tokens de diseño) y JavaScript moderno (ES6+).
- **Diseño de Alto Impacto (Rich Aesthetics)**: Paleta oscura charcoal (`#0A0A0C`), acentos mango cálido, fuego y neón.
- **CRO de Alta Conversión**: Integración directa con pedidos vía WhatsApp (`wa.me`), microinteracciones con efectos de brillo láser (*laser sweep shimmer*), pulsos en vivo e interacción táctil responsiva.
- **Iconografía Oficial Vectorial**: SVGs optimizados para Instagram, Facebook, TikTok y WhatsApp.
- **100% Responsivo**: Adaptado y verificado para pantallas móviles (iPhone, Android) y desktop.

---

## 💻 Ejecución Local

Para visualizar el sitio localmente, puedes servirlo con cualquier servidor HTTP estático:

```bash
# Con Python 3
python -m http.server 8080

# Con Node.js (npx)
npx serve .
```

Luego abre tu navegador en `http://localhost:8080/`.
